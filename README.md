# Churn-prediction-project
Predicción de churn de clientes usando el dataset real de Telco Customer Churn (7,043 clientes). Comparación de Regresión Logística vs. Random Forest con evaluación adecuada para clases desbalanceadas (AUC-ROC, Average Precision). Incluye EDA completo e importancia de variables. Python, scikit-learn, pandas.
